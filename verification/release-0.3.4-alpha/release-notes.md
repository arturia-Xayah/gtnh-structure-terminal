适用于 **GTNH 2.9.0**。下载下方唯一的安装 JAR，替换 `mods` 中旧版 GTNH现代化升级；联机时客户端与服务端使用相同版本。

### 本次更新
- 重做高级结构终端设置：圆角界面、布尔勾选框、可展开的线圈／玻璃选择列表，采用 NEI 原生图标和完整物品提示。
- 右键主机投影，Shift＋右键主机执行建造／替换／拆除；Shift＋右键空气打开设置。支持无仓室建造与仅替换线圈。
- 拆除新增“保留仓室”选项，默认开启；关闭后可回收空的基础 GT 仓室。装有物品或流体的仓室、特殊仓室及主机仍保留。
- AE 模式拆除材料直接存入已连接的网络。网络无法接收时保留方块；实际存入被拒绝的余料暂存在终端中，恢复连接后再次执行操作即可重试。
- 修复集成样板右键打开后立即关闭的问题。
- 修复聚合器成型后原生 LuV 外壳的材质覆盖，使外壳、主机和仓室采用连续底纹并保留功能图案。

For **GTNH 2.9.0**. Replace the previous GTNH Modernization Upgrade JAR in `mods` with the single installation JAR below. Multiplayer clients and servers must use the same version.

### Changes
- Redesigned advanced terminal settings with rounded controls, checkboxes, expandable coil/glass selectors, native NEI item rendering and full tooltips.
- Right-click a controller to project; sneak-right-click it to build, replace or dismantle. Sneak-right-click air to configure. Includes no-hatch building and coil-only replacement.
- Optional hatch retention during dismantling, enabled by default. Disable it to recover empty basic GT hatches; filled or special hatches and the controller remain in place.
- AE demolition returns go directly into the linked network. Blocks remain when the network cannot accept them. Rejected post-removal returns stay on the terminal until access is restored and the action is retried.
- Fixed Integrated Pattern closing immediately after opening.
- Fixed formed vault surface rendering on native LuV casings, with continuous surfaces across casings, controller and ports while retaining functional markings.
